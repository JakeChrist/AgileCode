# System Integration Oversight

Use this skill when separate components must operate together or changes affect several subsystems.

- Identify interactions, dependencies, and shared architectural constraints across subsystem boundaries.
- Ensure the responsible teams define and maintain compatible interfaces, data representations, behaviors, and assumptions.
- Coordinate integration throughout development, not just after each subsystem is declared complete.
- Examine evidence that combined components behave correctly together; individual ticket completion is not sufficient integration evidence.
- Identify inconsistencies, ownership gaps, and integration failures, then delegate investigation or correction to the responsible teams.
- Reassess integration priorities when changes in one subsystem affect others.

Maintain system-wide coherence without independently redesigning specialist-owned components. Escalate genuine cross-team architectural conflicts for appropriate engineering resolution.
